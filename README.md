# OmniRoute Status for Oh My Pi

Компактная панель квот OmniRoute для **OMP (Oh My Pi)**: остатки по аккаунтам и моделям, время сброса и обновление upstream-квот без сообщений в истории чата.

## Установка

```sh
omp plugin install github:gerasimovroman/omp-omniroute-status
```

Для локальной разработки:

```sh
git clone https://github.com/gerasimovroman/omp-omniroute-status.git
cd omp-omniroute-status
omp plugin link "$PWD"
```

Перезапустите OMP после установки или изменения исходников. Расширение использует встроенные пакеты OMP; отдельная сборка не нужна.

## Настройка

Адрес сервера **не задан в исходниках**. Перед первым запросом настройте `OMNIROUTE_BASE_URL` и API-ключ. Используйте HTTPS, если запрос проходит не через доверенное локальное соединение.

Адрес определяется в порядке:

1. `OMNIROUTE_BASE_URL` или `OMNIROUTE_URL`.
2. `url` или `baseUrl` в локальном `~/.omni-status.json`.

Ключ определяется в порядке:

1. `OMNIROUTE_API_KEY`.
2. `apiKey` в локальном `~/.omni-status.json`.
3. Файл `~/.omp/secrets/omniroute.key`.

Например, можно хранить только `baseUrl` в локальном JSON-файле, а ключ — в переменной окружения или отдельном файле секрета. Не добавляйте настройки и секреты в Git. Нестандартный CA подключайте через `NODE_EXTRA_CA_CERTS`; проверка TLS не отключается.

## Панель в OMP

| Команда | Действие |
| --- | --- |
| `/omni` или `/quota` | Открыть компактную панель в цветах текущей темы |
| `/omni --all` | Показать все модели, включая unlimited-квоты |
| `/omni codex` | Отфильтровать по провайдеру |
| `/omni flash` | Отфильтровать по имени квоты/модели |
| `/omni -r` или `/omni refresh` | Обновить upstream-квоты при открытии |
| `/omni --widget` | Показать постоянный виджет над редактором |
| `/omni --no-widget` | Скрыть виджет |

Управление в панели:

- **Esc** — закрыть и вернуться к редактору. Панель не сохраняется в чат.
- **r** — обновить квоты, не закрывая панель.
- **↑ / ↓**, **Page Up / Page Down**, **Home / End** — прокрутка длинного списка.

На узком терминале строки перестраиваются. Одинаковые значения квот группируются для компактности; это визуальная группировка, а не доказательство общего upstream-пула. Аккаунты одного провайдера отображаются отдельно. В RPC/неинтерактивном режиме команда сохраняет текстовый вывод; `--raw` выбирает ANSI-формат вместо Markdown.

## Инструмент для агента

`omni_status` принимает `provider`, `compact`, `refresh`, `format` (`markdown`, `text`, `json`). Для принудительного обновления перед чтением передайте `refresh: true`.

## CLI

Требуется Node.js 22.18+ с поддержкой запуска TypeScript без сборки:

```sh
node bin/omni-status.ts
node bin/omni-status.ts -c
node bin/omni-status.ts --json
```

## API

- `GET /api/usage/om-usage?format=json` — сводка квот.
- `GET /api/usage/:connectionId` — обновление квот соединения (аналог Refresh now).

Запросы используют Bearer-ключ и настроенный адрес сервера. Плагин не меняет провайдера моделей и не расходует reset credits. Права ключа должны разрешать используемые management-endpoints OmniRoute.
